# Learning Python

A collection of Python exercises organized by chapter.

## Structure

- `chapter-1/` - Basic output and introductory exercises
- `chapter-2/` - Variables and basic Python data types
- `chapter-3/` - Strings

Some programs use third-party packages. For example, the joke example requires `pyjokes`:

```powershell
python -m pip install pyjokes
python chapter-1/jokes.py
```

## Running an exercise

From the project root, run a script with Python:

```powershell
python chapter-2/var.py
```
